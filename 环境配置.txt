================================================================================
鲲鉴智策 · 环境配置说明
================================================================================

一、运行环境要求
--------------------------------------------------------------------------------
1. 浏览器（二选一即可，无需安装任何运行时）
   · Chrome / Edge 90 及以上（推荐）
   · Safari 15 及以上 / Android WebView（Android 7.0 及以上）
2. 操作系统：Windows / macOS / Linux / Android 均可
3. 网络：不需要。所有依赖（Tailwind 运行时、Excel 库）已本地化到 vendor/ 目录
4. 不需要：Node.js、Python、数据库、Web 服务器。直接双击 index.html 即可运行。
5. 可选：Node.js 18 及以上 —— 仅在需要"由 .env 生成 js/env.js"时使用（见第四节）。
   不安装 Node.js 也不影响系统运行，页面会回落到本地调试兜底配置。

二、依赖清单
--------------------------------------------------------------------------------
本项目无包管理器依赖，第三方库以静态文件形式内置，离线可用：

  路径                          名称与版本                    用途              许可
  ----------------------------  ----------------------------  ----------------  ----------
  vendor/tailwindcss.js         Tailwind CSS（Play 运行时）    原子类样式        MIT
  vendor/xlsx.bundle.js         xlsx-js-style 1.2.0           Excel 读写与样式  Apache-2.0

三、目录结构
--------------------------------------------------------------------------------
  index.html          页面骨架
  css/style.css       全局样式
  js/                 业务代码（19 个模块，按职责拆分，加载顺序见 README；
                      nlq.js 为对话式数据分析助手「秦思智能体」；
  vendor/             第三方静态依赖（Tailwind 运行时、xlsx-js-style）
  scripts/
  环境配置.txt        本文件

四、环境配置（敏感信息不入库）
--------------------------------------------------------------------------------
"环境变量"以如下链路落地：

    .env  →  node scripts/build-env.mjs  →  js/env.js
                    →  页面读取 window.KJ_ENV

五、本地运行
--------------------------------------------------------------------------------
方式一（最简单搜索）：https://si-qin1.github.io/kunjian1/，用 Chrome / Edge 打开。

方式二（推荐，等价于线上环境）：
   cd 项目根目录
   python3 -m http.server 8080
   # 浏览器访问 http://localhost:8080

   Node 环境也可以用：
   npx serve .

六、GitHub Pages 部署
--------------------------------------------------------------------------------
1. 将本目录全部文件推送到仓库 main 分支（保留 .nojekyll 文件）
2. 仓库 Settings → Pages → Source 选择 Deploy from a branch
3. 分支选 main，目录选 / (root)，保存


注意事项：
  · 页面使用相对路径引用资源，放在仓库根目录或任意子目录都能正常加载
  · 推送前务必确认 .env 未入库、js/env.js 为空值模板（见第四节第 3 条）
  · GitHub Pages 为 HTTPS，localStorage 可正常使用
  · 首次访问后浏览器会缓存静态资源，更新代码后建议强制刷新（Ctrl/Cmd + Shift + R）

七、Android 打包（可选）
--------------------------------------------------------------------------------
如需打包成 APK，需要以下环境（本仓库只包含 Web 工程，不含 Android 壳工程）：
  · JDK 17
  · Android SDK Platform 34 + Build-Tools 34.0.0
  · Gradle 8.7（AGP 8.5.2 与 Gradle 9.x 不兼容，注意版本匹配）
  · 签名文件 keystore（自行生成，不要提交到仓库）

  Android 壳工程的做法：新建 WebView 项目，把本目录全部文件放入
  app/src/main/assets/，加载 file:///android_asset/index.html 即可。

八、数据与存储说明
--------------------------------------------------------------------------------
  · 业务数据保存在浏览器 localStorage，键名 kunyan_v3
  · 账号表保存在 localStorage，键名 kunyan_users_v1；会话键 kunyan_session_v1
  · 清除浏览器数据会导致业务数据丢失，重要数据请用「导出 JSON 备份」留档
  · 换浏览器 / 换设备不会自动同步数据，需通过备份文件迁移

九、常见问题
--------------------------------------------------------------------------------
Q1 打开后页面没有样式（只有纯文字）
   检查 css/style.css 与 vendor/tailwindcss.js 是否在同一目录层级被正确引用；
   若从压缩包解压后只拷贝了 index.html，请把整个目录一起拷贝。

Q2 导出的 Excel 打不开或提示损坏
   确认 vendor/xlsx.bundle.js 存在且未被杀毒软件拦截；导出后请用 Excel 2016+
   或 WPS 打开。

Q3 预测按钮点了没反应
   打开浏览器控制台查看是否有报错；常见原因是本地文件被浏览器安全策略限制，
   改用第五节的本地服务器方式打开即可。
